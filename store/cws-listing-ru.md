# Chrome Web Store Listing — Русский

## Extension Name (manifest name)
AyaMir - Website Blocker, Pomodoro Timer & Task Manager

## Short Description (132 chars max)
Блокируйте отвлекающие сайты и запускайте 25-минутные сеансы Pomodoro. Бесплатно, без регистрации.

## Detailed Description
AyaMir объединяет таймер Pomodoro и блокировку сайтов. Выберите сайты, которые нужно приостановить, и запустите 25-минутный сеанс фокуса — или используйте таймер без блокировки. Регистрация не нужна. Настройки и история сеансов хранятся на вашем устройстве.

ПЕРВЫЙ СЕАНС ФОКУСА
1. Откройте AyaMir и перейдите в режим фокуса.
2. Нажмите «Выбрать сайты» и проверьте домены, которые хотите блокировать.
3. Выберите 25 минут и запустите таймер. Также доступны сеансы на 15, 45, 60 и 90 минут.

Таймер продолжает работать после закрытия всплывающего окна. Откройте его снова, чтобы увидеть оставшееся время. Если сайты не выбраны, можно пользоваться только таймером.

УПРАВЛЯЙТЕ БЛОКИРОВКОЙ
- Блокируйте выбранные сайты на время сеанса фокуса.
- Добавляйте домены вручную или используйте готовые категории.
- Настройте расписание блокировки по дням и часам.
- Постоянная блокировка включается отдельно. Если она активна, выбранные сайты остаются заблокированы после завершения таймера. Отключите её в настройках блокировки, если хотите блокировать сайты только на время сеанса.
- Жёсткий режим необязателен и выключен по умолчанию при новой установке. Если включить его для сеанса, завершить этот сеанс досрочно не получится.

ВЫБЕРИТЕ ЗАДАЧУ ДЛЯ СЕАНСА
- Добавляйте задачи с приоритетами и сроками.
- Редактируйте и переносите задачи, выбирайте цель дня.
- Сохраняйте страницу, ссылку или выделенный текст как задачу через контекстное меню.
- Добавляйте задачи через командную палитру без открытия основного окна.

СЛЕДИТЕ ЗА ПРОГРЕССОМ
Смотрите завершённые сеансы и общее время фокуса. Получайте XP за задачи и сеансы, открывайте достижения и поддерживайте ежедневную серию.

ЛОКАЛЬНЫЕ ДАННЫЕ, БЕЗ РЕГИСТРАЦИИ
Задачи, настройки и история сеансов хранятся локально в браузере. Инструменты фокуса работают офлайн. Экспортируйте резервную копию в JSON и импортируйте её для восстановления данных. Аккаунт и подписка не нужны, рекламы нет. Исходный код доступен по лицензии MIT.

Доступны русский, английский, испанский, упрощённый китайский и хинди.

Выберите задачу. Приостановите отвлекающие сайты. Начните один сеанс фокуса.
